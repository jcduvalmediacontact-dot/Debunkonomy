### Décompte mécanique du registre, et état des éléments du chemin critique

La fiche demande d'actualiser *les huit arbitrages du chemin critique*. Aucun décompte n'est recopié : le script ci-dessous lit `corpus/arbitrages.yaml` (clés `arbitrages`, `falsifieurs`, `pieces_de_conception_manquantes`). Fichier : un script de relevé de la session, non versé.

```python
# -*- coding: utf-8 -*-
"""Décompte du registre corpus/arbitrages.yaml, par liste et par statut.

Lecture seule. Aucun chiffre n'est recopié à la main : tout est lu dans le
fichier au moment de l'exécution. Écrit pour le brouillon d'alignement
L1.C29 (« actualiser les huit arbitrages du chemin critique »).
"""
import collections
import pathlib
import subprocess
import sys

import yaml

DEPOT = pathlib.Path(r"C:\Users\jcduv\Documents\GitHub\debunkonomy")
REGISTRE = DEPOT / "corpus" / "arbitrages.yaml"
LISTES = ("arbitrages", "falsifieurs", "pieces_de_conception_manquantes")
STATUTS = ("ouvert", "oriente", "arbitre", "conditionnel")

# Identifiants que L1.C29 nomme dans son corps ou ses annexes.
NOMMES_PAR_C29 = ["A8", "F1", "P18", "F7", "F6", "F2", "F4", "P55", "P56",
                  "A30", "A35", "A35b", "A37"]
# Entrées qui gouvernent L1.C29 sans que le chapitre les nomme.
GOUVERNANTS_NON_NOMMES = ["A44", "A43", "A45", "EXCEDENT-DU-SYMPOSIUM", "A36",
                          "A32", "A46", "F10", "F13", "F14", "RECALIBRAGE",
                          "CRITERE-L25", "A34", "REGLE-D-EMISSION",
                          "TEST-APPORT-PROPRE", "PORTEFEUILLE-COMPARAISON"]


def main():
    try:
        sha = subprocess.run(
            ["git", "-C", str(DEPOT), "rev-parse", "--short", "HEAD"],
            capture_output=True, text=True, check=True,
        ).stdout.strip()
    except Exception as exc:  # lecture seule, l'échec n'arrête pas le compte
        sha = f"inconnu ({exc})"
    donnees = yaml.safe_load(REGISTRE.read_text(encoding="utf-8"))
    print(f"registre : corpus/arbitrages.yaml, revision {donnees.get('revision')}")
    print(f"commit HEAD : {sha}")
    total = 0
    tous = {}
    for liste in LISTES:
        entrees = donnees.get(liste) or []
        total += len(entrees)
        compte = collections.Counter(e.get("statut") for e in entrees)
        inconnus = sorted(set(compte) - set(STATUTS), key=str)
        ligne = " ; ".join(f"{s} {compte.get(s, 0)}" for s in STATUTS)
        print(f"{liste} : {len(entrees)} entrées — {ligne}"
              + (f" ; statuts hors échelle {inconnus}" if inconnus else ""))
        for s in STATUTS:
            ids = [str(e.get("id")) for e in entrees if e.get("statut") == s]
            if ids:
                print(f"    {s} : {', '.join(ids)}")
        for e in entrees:
            tous[str(e.get("id"))] = (liste, e.get("statut"), e.get("maj"))
    print(f"total des trois listes : {total}")
    for titre, groupe in (("nommés par L1.C29", NOMMES_PAR_C29),
                          ("gouvernants non nommés par L1.C29",
                           GOUVERNANTS_NON_NOMMES)):
        print(f"--- {titre} ---")
        for i in groupe:
            if i in tous:
                liste, statut, maj = tous[i]
                print(f"{i} : {liste}, statut {statut}, maj {maj}")
            else:
                print(f"{i} : ABSENT du registre")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

## 4. Branches ouvertes à exposer

**A. A35b — la contrepartie et l'extinction du passif de l'émetteur (`ouvert`).**
- *Branches générales* (refonte § 4) : passif exigible ; passif non exigible ; fonds propres négatifs assumés.
- *Candidats de contrepartie discutés par le chapitre* : (1) certificat de qualification — échoue sur le contrôle ; (2) créance sur reflux futurs — non reconnaissable sous IPSAS 47 si le référentiel s'applique, et érodée par le succès ; (3) ressource conservée (IPSAS 51) — trois conditions non acquises, dont le contrôle, que le commun n'a pas ; (4) aucune contrepartie, fonds propres négatifs assumés ; (5) créance adossée au démurrage — assiette indépendante de la composition, érodée par l'encours. Exclue tant qu'A35 tient : l'allocation portée au passif de chaque banque centrale receveuse, P«Cette architecture contredit A35a ; elle n'est pas comptablement méconnaissable.» (section `## LA MATRICE COMPTABLE D'A35b — 2026-09-09 : ÉCRITE, RÉFUTÉE DEUX FOIS, REFAITE DEUX FOIS`).
- *Critères* : le référentiel applicable (A37) ; le contrôle ; la mesure fiable ; la reconnaissance d'un flux futur ; l'obligation présente (le précédent lu en identifie une d'intérêt, dont le transport n'est pas établi) ; le rythme d'érosion (v5) ; la part de l'excédent du reflux disponible après ses affectations ; l'ordre de service en liquidation. Questions de la revue : A«Confirmez-vous que l'insuffisance d'actifs ne fait pas disparaître le passif, y compris pour une institution dont la situation nette devient négative ?» (`protocoles/revue-comptable-a35b.md`).
- *Ce que le texte peut dire sans conclure* : la construction du Cahier ne tient pas en l'état ; aucune contrepartie n'est aujourd'hui identifiée ; des fonds propres négatifs sont représentables ; la revue comptable est le prochain jalon, aucun modèle macroéconomique avant elle.

**B. A37 — la forme de l'émetteur (`oriente`).** *Branches* (passe-2, 2026-09-07) : organisation internationale créée par traité ; institution financière adossée à des États ; fondation de droit national ; filiale d'une institution existante — avec la priorité de modélisation arrêtée. *Critères* : référentiel comptable, qualité d'organisme public, fonds propres négatifs ou non, protection du caractère définitif. *Sans conclure* : le test d'actif du § 4 et la condition du § 5 en dépendent.

**C. EXCEDENT-DU-SYMPOSIUM — le sort du solde (`oriente`).** *Branches* : dépenser, conserver, redistribuer (A2 quater). *Acquis* : fonctionnement, première affectation aux guichets (D75). *Critère* : la formule. *Sans conclure* : le gage de la branche « fonds propres négatifs » dépend de ce qui reste.

**D. A30 — la qualification juridique de l'unité (`oriente`).** *Branches* : avoir de réserve (mécanique DTS sans la nature), instrument sui generis par traité portant une dette collective à reflux collectif. *Critères* : fiche de spécification ; conditions d'IPSAS 51. *Sans conclure* : le point bloquant a un mécanisme (l'encours), pas de solution.

**E. Ce qui décide du dossier (F1, F6, F10, F14 `ouvert` ; A43 (3b) sous deux conditions).** *Branches* : l'état du dossier se construit sur la conclusion de l'auteur et le registre calculé, ou sur une liste propre au corpus. *Critères* : ce qui est arbitré (A43, A44, A45), ce qui ne l'est pas (A35b, F1, F10), ce qui dépend de tiers (revue comptable, adhésion des créanciers). *Sans conclure* : aucun falsifieur n'est levé ; la conclusion de l'auteur n'est ni un succès ni un échec.
